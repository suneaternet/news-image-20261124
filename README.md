"The World in Six" — a one-page broadsheet poster summing up Tuesday 24 November 2026 in six stories: Nvidia reinstates Jensen Huang as CEO, Ukraine sinks a Russian warship off Libya, three tankers hit mines in the Strait of Hormuz, a factory fire kills 26 in Banten, Pakistan's first astronaut heads for Tiangong, and Russia warns Estonia of open war. Drawn from scratch in stdlib-only Python: a hand-built 5x7 bitmap face, a tiny PNG encoder, no imaging library at runtime.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024). In the grader the program writes to `/output/entry.png` instead.
